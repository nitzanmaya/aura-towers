# Aura Towers

דף נחיתה ליוקרה עבור פרויקט Aura Towers. React 18, Vite, Tailwind CSS ו-lucide-react.

```bash
npm install
npm run dev     # פיתוח מקומי
npm run build   # בנייה לתיקיית dist
```

הקומפוננטה הראשית: `src/AuraTowers.jsx`. נתוני הדירות (`UNITS`) והטקסטים הם דוגמה ויש להחליפם בנתוני הפרויקט.
